HTTP Request Node

Призначення

Виконує HTTP запити до будь-якого API

Можливості

  • • GET, POST, PUT, DELETE запити
  • • Аутентифікація (Bearer, OAuth, API Key)
  • • Headers та параметри
  • • JSON/XML обробка

Приклад використання

Отримання даних з CRM, відправка повідомлень в Telegram

Webhook Node

Призначення

Приймає дані від зовнішніх сервісів в реальному часі

Можливості

  • • Унікальний URL для кожного workflow
  • • Підтримка POST/GET методів
  • • Обробка JSON, Form-data, XML
  • • Аутентифікація запитів

Приклад використання

Прийом форм з сайту, інтеграція з платіжними системами

Code Node

Призначення

Виконує JavaScript код для обробки даних

Можливості

  • • Повний JavaScript (ES6+)
  • • Доступ до вхідних даних
  • • Бібліотеки: moment, lodash
  • • Асинхронні операції

Приклад використання

Трансформація даних, математичні обчислення, парсинг тексту

IF Node

Призначення

Розгалужує workflow на основі умов

Можливості

  • • Порівняння значень (=, !=, >, <)
  • • Перевірка на існування
  • • Regex валідація
  • • Множинні умови (AND/OR)

Приклад використання

Фільтрація даних, маршрутизація повідомлень, валідація

Schedule Trigger

Призначення

Запускає workflow автоматично за розкладом

Можливості

  • • Інтервали (секунди, хвилини, години)
  • • Cron вирази для складних розкладів
  • • Конкретні дні та час
  • • Timezone підтримка

Приклад використання

Щоденні звіти, моніторинг, backup, розсилки
